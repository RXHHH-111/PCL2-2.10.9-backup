## 怎么用

PCL2 是绿色免安装程序。解压后把 `Plain Craft Launcher 2.exe` 放到任意文件夹（建议单独目录，例如 `D:\\我的世界\\`），双击运行即可。首次启动会在同目录生成 `PCL` 配置文件夹和 `.minecraft` 游戏目录。

### ⚠️ 装好后第一件事：关掉自动更新

否则 PCL 会自动升级到不可用的新版，且**降不回来**。步骤：先断网启动 → 设置 → 其他 → 最下方“启动器”一栏 → “启动器更新”改为 **关闭更新提示** → 弹窗选“我知道我在做什么”。之后可正常联网使用。

（此操作路径来自社区教程，见文末“背景”一节。）

## 如何验证你下到的是原版

这一节比压缩包本身更有用——请务必看完再双击。

### &#x20;核对哈希（最硬的证据）

解压后在 PowerShell 里对**压缩包**执行：

```powershell
Get-FileHash .\\PCL2-2.10.9-win.zip -Algorithm SHA256
```

期望值：

```
4FADCA47D57D1F545165B62A1F6971908F937EB735BF9461899DF091DBEA227D
```

对解压出来的 **exe** 执行：

```powershell
Get-FileHash '.\\Plain Craft Launcher 2.exe' -Algorithm SHA256
```

期望值：

```
45F546ED00D0ED250E28F3FEA009E219F252DE5716AC0B32A123E295E5B5180D
```

对不上，就是被改过的，直接删，别运行。

### 3\. 核对文件属性

右键 exe → 属性 → 详细信息，应该看到：

* 文件说明：`Plain Craft Launcher 启动器`
* 产品名称：`Plain Craft Launcher`
* 文件版本 / 产品版本：`2.10.9.0`
* 版权：`Copyright © 龙腾猫跃 2016. All Rights Reserved.`
* 大小：`5,760,000 字节`

版本号被人为改成 2.99 或 2.14 而大小对不上，就是动过的。

### 4\. 关于“数字签名”

**PCL2 官方版本本来就没有数字签名。**

```powershell
Get-AuthenticodeSignature '.\\Plain Craft Launcher 2.exe'   # Status: NotSigned
```

所以：**不要**因为“未签名”就断定有毒（这是它一贯的状态），也**不要**因为“能正常跑起来”就断定安全。判据只有哈希、来源，以及文件是不是只有这一个 exe。

### 5\. 危险信号清单

出现任意一条，立刻停手：

* 解压后除了 `Plain Craft Launcher 2.exe` 还有别的 dll、bat、安装器、“配置工具”
* 双击后先弹安装向导 / 要你关闭杀毒软件 / 要管理员权限装东西
* 压缩包大小明显不对（原包约 2.42 MiB）
* 来源页没有版本号、没有哈希、没有作者信息
* 文件名带“绿色版”“破解版”“加速版”“整合版”

### 6\. 还不放心？ 

把 exe 传到 VirusTotal 查多引擎结果。注意：上传等于把文件公开给对方，纯公益软件无所谓，但别传任何私人配置。
